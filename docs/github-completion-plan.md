# GitHub project completion plan

User-approved scope: make downloads/onboarding clear, add accurate discovery metadata, community/reporting documentation, genuine visual demonstration, and a public repeatable native source-build/package workflow. No promises of universal compatibility, legal certification, guaranteed popularity, signing/notarization or physical-device tests without evidence.

## Tasks and ownership

- [x] Root: README download table, quick start, screenshot gallery, real native demonstration, social preview asset and repository metadata/topics.
- [x] Community worker: CONTRIBUTING, SUPPORT, SECURITY, conduct guidance, issue/PR templates, changelog and bounded roadmap/manual acceptance matrix.
- [x] Automation worker: public manually dispatched matched-source validation on all three native targets, no hardcoded private run dependencies, bounded artifacts, doc-only checks and efficient source CI path filters. No compiler cache is stored.
- [x] Root/reviewer: validate links/templates/source binding/privacy, execute native workflow and check its evidence, publish source/docs changes and verify rendered GitHub pages/settings.
